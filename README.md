This is an [Astro](https://astro.build) portfolio site.

## Getting Started

First, run the development server:

```bash
bun dev
```

Open [http://localhost:4321](http://localhost:4321) with your browser to see the result.

You can start editing the page by modifying `src/pages/index.astro`. The page auto-updates as you edit the file.

Run `bun run build` to create a production build in `dist/`, then use `bun run preview` to test it locally.
